# Internationalization

Litemacro follows **Minecraft → Options → Language**. Select English (US) or 简体中文（中国） and reopen Litemacro. Other Minecraft languages fall back to English for untranslated Litemacro text. Resource packs can override the usual `assets/macro_builder/lang/<language_code>.json` files.

All five Minecraft versions use the same translation catalogs in `shared/resources/assets/macro_builder/lang/`. Their Gradle projects include the shared resources and `shared/java/` directly, so edit a translation once for every supported version. Build from the complete repository checkout.

To add a language, copy `en_us.json` to the corresponding Minecraft language code, translate its values, and keep its keys. Preserve numbered placeholders such as `%1$s`; translators may reorder them. Write a literal percent sign as `%%`. Do not assemble sentences from translated fragments. Keep IDs and examples such as `minecraft:iron_sword`, `true`, `false`, `held`, `move=true`, and `${player.pos}` intact: these are macro input syntax.

Use `Component.translatable(key, arguments)` for Minecraft widgets and `MacroText.tr(key, arguments)` where a custom renderer requires a String. Resolve translations when displaying text. Component names, help, and parameter labels resolve dynamically; group IDs, output IDs, item field capabilities, and saved macro data remain independent of translations. The English component names also remain available for searching and legacy component references. Macro names, notes, chat messages, and marketplace submissions are user content and are displayed literally.

Each version's `build` runs `validateTranslations` and `i18nTest`. The checks cover key parity across languages, source references, numbered placeholders, language switching, resource pack overrides, Unicode wrapping, and saved macro compatibility. mc26.3 also runs its existing numeric and cloud vault regressions.

GUI checks in a development client:

- Switch between English and 简体中文, reopen the macro list, builder, import screen, marketplace, and settings dialogs; check both the normal and smallest supported GUI scale.
- Search by a Chinese name, its English name, and its component ID. Open item pickers and check descriptions with no spaces.
- Bind a key: Esc cancels; Backspace/Delete clears. Toggle random delay, then cancel; the macro must remain unchanged. Invalid ranges stay in the dialog with an error.
- Import test macros and exercise success, failure, stopping, and held-input release in both languages.
